# 🛒 Online Auction System

A modern and user-friendly **Online Auction System** developed to simplify the traditional auction process through a secure and efficient digital platform. This application allows users to create auctions, place bids in real time, and monitor auction activities from anywhere using an internet connection.

🌐 **Live Demo:**  
https://auction-system-2-7wey.onrender.com/

---

# 📌 Project Overview

The **Online Auction System** is a web-based platform designed for buyers and sellers to participate in auctions online. Sellers can upload products with auction details, while buyers can browse products and place bids securely in real time. The system automatically updates the highest bid and ensures transparency throughout the auction process.

This project demonstrates full-stack web development concepts including authentication, database management, bidding systems, and responsive web design.
